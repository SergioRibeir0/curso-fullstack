# Curso Full-Stack — diário de estudos

Repositório onde registro minha trilha de fundamentos full-stack: código dos exercícios e anotações de cada módulo, versionados com git desde o primeiro dia.

Faz parte do meu caminho de transição para tecnologia. O foco principal é AI Engineering, e esta trilha reforça a base de desenvolvimento web.

## Trilha

- **Módulo 1 — HTML e CSS** (em andamento)
- Próximos temas: JavaScript e TypeScript, SQL, React e Next.js, Node.js

## Módulo 1 — Página de portfólio

Página estática em HTML e CSS puros (`modulo-1/`), com:

- menu de navegação com botão de chamada
- cards de apresentação ("Sei fazer", "Estou aprendendo", "Quero aprender")
- seção de destaque e rodapé
- paleta de cores com variáveis CSS (`:root`)

Para ver, abra `modulo-1/index.html` no navegador.
